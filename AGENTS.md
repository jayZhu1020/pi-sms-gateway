# Repository workflow

Read and follow [.agents/skills/pi-sms-pr-workflow/SKILL.md](.agents/skills/pi-sms-pr-workflow/SKILL.md) before changes.

- Keep implementation plans, milestone breakdowns, and deployment proposals outside this repository, local-only.
- Each PR must have at most 300 added plus deleted lines, including tests, configuration, and documentation.
- Split work into independently achievable, testable tasks before publishing.
- Use a separate `codex/` branch and PR against `main`. The user reviews and merges; never auto-merge or push directly to main.
