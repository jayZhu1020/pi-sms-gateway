# Repository workflow

For every change in this repository, read and follow
[the Pi SMS PR workflow skill](.agents/skills/pi-sms-pr-workflow/SKILL.md).

Use a separate descriptive `codex/` branch for each logical change, push it,
and open a pull request targeting `main`. The user reviews and merges.
Do not commit or push directly to `main`, merge PRs, or enable auto-merge.
